# Biblioteca Obsidiana — GitHub Pages

Versão estática em HTML único.

## Como publicar

1. Crie um repositório no GitHub.
2. Envie o arquivo `index.html`.
3. Vá em `Settings > Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha a branch `main` e pasta `/root`.
6. Salve e aguarde o link.

## Recursos

- Busca Google Books
- Busca Open Library
- Busca Gutendex/Project Gutenberg
- Catálogo A–Z
- 80 livros por página
- Filtro por idioma
- Capa, sinopse, autor, idioma, ano e ISBN
- Favoritos no navegador
- Preços por links oficiais

## Limites

Esta versão não tem backend, login real, admin real, Mercado Pago real ou comparação automática de frete/preço.
